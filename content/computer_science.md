# Computer Science Handbook (Demo Content)

## 1. Number Systems
Computers store everything in binary (base 2), using only the digits 0 and 1. A single binary digit is a bit; eight bits make a byte. Decimal is base 10, octal is base 8 and hexadecimal is base 16 (digits 0-9 and A-F). To convert decimal to binary, divide the number repeatedly by 2 and read the remainders from bottom to top. For example, 13 in decimal is 1101 in binary. Hexadecimal is popular because one hex digit represents exactly four bits. Negative integers are usually stored using two's complement: invert all bits and add 1.

## 2. Boolean Logic and Logic Gates
Boolean algebra works with true (1) and false (0). The basic gates are AND (output 1 only if all inputs are 1), OR (output 1 if any input is 1) and NOT (inverts the input). NAND and NOR are universal gates: any circuit can be built using only one of them. XOR outputs 1 when the inputs differ. De Morgan's laws state that NOT(A AND B) equals (NOT A) OR (NOT B), and NOT(A OR B) equals (NOT A) AND (NOT B). A truth table lists the output for every input combination.

## 3. Computer Architecture
The CPU has three main parts: the Arithmetic Logic Unit (ALU) performs calculations, the Control Unit directs the flow of instructions, and registers are tiny, very fast storage locations. The CPU repeats the fetch-decode-execute cycle: fetch an instruction from memory, decode what it means, then execute it. Memory hierarchy goes from fast and small to slow and large: registers, cache, RAM, then secondary storage such as SSDs. RAM is volatile, meaning it loses its contents without power, while ROM and flash storage are non-volatile. The von Neumann architecture stores both programs and data in the same memory.

## 4. Operating Systems
An operating system manages hardware and provides services to programs. Its main jobs are process management, memory management, file management and device management. A process is a running program; a thread is a lightweight unit of execution inside a process. The scheduler decides which process uses the CPU, using algorithms such as First-Come-First-Served, Round Robin (each process gets a fixed time slice) and Priority scheduling. Virtual memory lets a computer use disk space as an extension of RAM through paging. A deadlock happens when processes wait forever for resources held by each other; it needs mutual exclusion, hold and wait, no preemption and circular wait to occur together.

## 5. Data Structures
An array stores elements in contiguous memory and gives O(1) access by index, but inserting in the middle costs O(n). A linked list stores nodes connected by pointers, allowing O(1) insertion at a known position but O(n) search. A stack is Last-In-First-Out (LIFO) with push and pop operations, used for function calls, undo features and expression evaluation. A queue is First-In-First-Out (FIFO) with enqueue and dequeue operations, used in printer spooling and CPU scheduling. A binary tree has at most two children per node; a binary search tree keeps smaller values on the left and larger on the right, giving O(log n) search when balanced. A hash table maps keys to positions using a hash function and offers average O(1) lookup, with collisions handled by chaining or open addressing. A graph is a set of vertices connected by edges and models networks, maps and social connections.

## 6. Algorithms and Complexity
An algorithm is a finite, step-by-step procedure for solving a problem. Big-O notation describes how running time grows with input size n in the worst case. Common classes from fastest to slowest are O(1) constant, O(log n) logarithmic, O(n) linear, O(n log n), O(n squared) quadratic and O(2 to the n) exponential. Linear search checks each item in O(n). Binary search halves a sorted list each step and runs in O(log n). Bubble sort repeatedly swaps adjacent items and is O(n squared). Merge sort splits the list, sorts each half and merges them in O(n log n). Quick sort picks a pivot and partitions the list; it is O(n log n) on average. Recursion solves a problem by calling the same function on a smaller input and needs a base case to stop.

## 7. Databases
A database is an organised collection of data, managed by a Database Management System (DBMS). A relational database stores data in tables of rows (records) and columns (fields). A primary key uniquely identifies each row in a table. A foreign key is a column that refers to the primary key of another table and links the two tables. SQL is the standard language: SELECT reads data, INSERT adds rows, UPDATE changes rows and DELETE removes them. A JOIN combines rows from two tables based on a related column. Normalisation reduces redundancy: first normal form removes repeating groups, second removes partial dependencies and third removes transitive dependencies. ACID properties (Atomicity, Consistency, Isolation, Durability) guarantee reliable transactions.

## 8. Computer Networks
A network connects computers so they can share data and resources. A LAN covers a small area such as a school, a WAN covers a large area and the Internet is a global network of networks. The OSI model has seven layers: Physical, Data Link, Network, Transport, Session, Presentation and Application. The TCP/IP model groups these into four layers. IP addresses identify devices; IPv4 uses 32 bits and IPv6 uses 128 bits. TCP provides reliable, ordered delivery with acknowledgements, while UDP is faster but does not guarantee delivery. DNS translates domain names into IP addresses. HTTP is the protocol of the web and HTTPS adds encryption using TLS. A router forwards packets between networks, and a switch connects devices within one network.

## 9. Programming and Object-Oriented Concepts
A variable stores a value, and a data type defines what kind of value it is, such as integer, float, string or boolean. Control structures include selection (if/else) and iteration (for and while loops). A function groups reusable code and can take parameters and return a value. Object-oriented programming organises code into classes (blueprints) and objects (instances). Its four pillars are encapsulation (bundling data with methods and hiding internals), inheritance (a class reuses another class's features), polymorphism (the same method name behaves differently for different classes) and abstraction (exposing only essential details). A compiler translates a whole program into machine code before running, while an interpreter translates and runs it line by line.

## 10. Cybersecurity Basics
The CIA triad describes the goals of security: Confidentiality, Integrity and Availability. Encryption scrambles data so only someone with the key can read it. Symmetric encryption uses one shared key; asymmetric encryption uses a public key to encrypt and a private key to decrypt. A hash function produces a fixed-size fingerprint of data and cannot be reversed, which makes it suitable for storing passwords with a salt. Phishing tricks users into revealing credentials, malware is software designed to cause harm, and a denial-of-service attack floods a system to make it unavailable. A firewall filters network traffic, and multi-factor authentication requires more than one proof of identity.
